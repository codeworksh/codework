## Providers

CodeWork supports subscription-based providers via OAuth and API key providers via environment variables.

| Provider                                                | Access                           |
| ------------------------------------------------------- | -------------------------------- |
| [OpenAI Codex](/docs/models/openai-codex)               | ChatGPT Plus or Pro subscription |
| [GitHub Copilot](/docs/models/github-copilot)           | GitHub Copilot subscription      |
| [OpenRouter](/docs/models/openrouter)                   | `OPENROUTER_API_KEY`             |
| [Anthropic, OpenAI, Gemini, xAI](/docs/models#api-keys) | API key                          |

See [Models & Pricing](/docs/models) for the full list.
