CodeWork reads your codebase, plans changes, edits files, and runs commands to check its work. You pick the model, from a ChatGPT or Copilot subscription, an API key, or a model running on your own machine.

## Work Safely

CodeWork has no permission prompts: it runs shell commands and edits files without asking. Run it in a git repository so you can review and undo its changes, and use a [sandbox](/docs/cli/using#sandboxes) when you don't want it touching your machine.
