Requires a ChatGPT Plus or Pro subscription.

## Sign In

Sign in with your browser:

```bash
codework auth login --openai-codex
```

No browser on this machine, such as over SSH? Use a device code instead:

```bash
codework auth login --openai-codex --device
```

## Run

```bash
codework run --provider openai-codex --model gpt-5.6-luna "Explain this repository"
```


## Pricing

Usage counts against your ChatGPT plan's limits. The cost in CodeWork's usage summary is the API-rate equivalent, useful for comparing models but not what you're billed.
