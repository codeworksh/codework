---
title: OpenAI Codex
description: Use GPT-5 and Codex models through your ChatGPT plan.
---

Requires a ChatGPT Plus or Pro subscription.

## Sign in

Sign in with your browser:

```bash
codework auth login --openai-codex
```

No browser handy? Use a device code instead:

```bash
codework auth login --openai-codex --device
```

## Run

```bash
codework run --provider openai-codex --model gpt-5.6-luna "Explain this repository"
```
