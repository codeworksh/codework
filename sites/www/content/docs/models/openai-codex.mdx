Sign in with your ChatGPT account. Usage counts against your ChatGPT plan's limits.

## Sign in

```bash
codework auth login --openai-codex
```

CodeWork opens the sign-in page in your browser and waits for the browser to return to `localhost:1455`. If that port is taken, paste the redirect URL from your browser when CodeWork asks for it.

No browser on this machine, such as over SSH? Use a device code instead. It needs no local port:

```bash
codework auth login --openai-codex --device
```

To store the login on a running `codework serve` instead of this machine, add `--server ws://127.0.0.1:7433/rpc/v1`.

## Run

```bash
codework run --provider openai-codex --model gpt-5.6-luna "Explain this repository"
```

## Check or remove the login

```bash
codework auth status --openai-codex
codework auth logout --openai-codex
```

The login renews itself when it expires. `codework auth refresh --openai-codex` renews it now.
