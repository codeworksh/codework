A **model** writes CodeWork's answers and decides which tools to call. A **provider** is the service CodeWork reaches the model through. You can use any model in the [catalog](/docs/models/catalog) from a provider you have credentials for, and switch per run, per project, or mid-conversation in your editor.

## Connect a provider

### Subscriptions

Sign in once and use the models included in your plan.

| Provider                                      | Sign in                                |
| --------------------------------------------- | -------------------------------------- |
| [OpenAI Codex](/docs/models/openai-codex)     | `codework auth login --openai-codex`   |
| [GitHub Copilot](/docs/models/github-copilot) | `codework auth login --github-copilot` |

CodeWork stores logins in `~/.codework/aikit/auth.json`. It renews OpenAI Codex logins when they expire. GitHub Copilot logins don't expire.

### API keys

Set the provider's environment variable and CodeWork picks it up. No sign-in step.

| Provider                              | Provider ID  | Environment variable                 |
| ------------------------------------- | ------------ | ------------------------------------ |
| [OpenRouter](/docs/models/openrouter) | `openrouter` | `OPENROUTER_API_KEY`                 |
| Anthropic                             | `anthropic`  | `ANTHROPIC_API_KEY`                  |
| OpenAI                                | `openai`     | `OPENAI_API_KEY`                     |
| Google Gemini                         | `google`     | `GEMINI_API_KEY` or `GOOGLE_API_KEY` |
| xAI                                   | `xai`        | `XAI_API_KEY`                        |

These are the most common. Every other provider in the catalog works the same way. Run `codework models providers` for the full list of IDs. The variable each provider reads is under `provider.env` in `~/.codework/models.gen.json`.

### Your own models

Local models (Ollama, LM Studio, vLLM) and private gateways are added in settings. See [Custom models](/docs/models/custom).

## Choose a model

Pass `--provider` and `--model` on a run:

```bash
export OPENROUTER_API_KEY="..."

codework run --provider openrouter --model deepseek/deepseek-v4.1-flash "Plan the database migration"
```

Or set a default for every run in your [settings](/docs/customize/settings#model):

```jsonc title="~/.codework/settings.jsonc"
{
	"model": { "provider": "openrouter", "id": "deepseek/deepseek-v4.1-flash", "thinkingLevel": "medium" },
}
```

Without any settings, CodeWork uses `openai/gpt-5.6-luna` at `medium` thinking, which needs `OPENAI_API_KEY`.

In an editor, use the model and Thinking Effort pickers instead. They list every model from the providers CodeWork has credentials for. See [ACP](/docs/integrations/acp#sessions-and-configuration).

## Thinking levels

Reasoning models can think before they answer. A higher thinking level trades speed and cost for depth. CodeWork uses one scale for every provider and maps it to each provider's own setting:

`off` · `minimal` · `low` · `medium` · `high` · `xhigh` · `max`

Each model supports only some of these levels. If you ask for one it doesn't support, CodeWork uses the next level up, or the model's highest level. Pass `--thinking <level>` on a run, or set `thinkingLevel` in settings. The [catalog](/docs/models/catalog#thinking-levels) lists the levels for each Codex model.

## Pricing

CodeWork doesn't charge for models. You pay your provider, at their rates or through your plan. Every run ends with a usage summary that shows tokens and an estimated cost, based on the catalog's per-million-token prices:

```text
── usage ───────────────────────────────────────────────────────────────
model    openai-codex/gpt-5.6-luna
tokens   6,172 input · 1,377 output · 412 reasoning · 19,581 total
cache    12,032 read · 0 write
cost     $0.003127 · 3 turns
```

See [Catalog & prices](/docs/models/catalog) for the price of each model and how the estimate is worked out.
