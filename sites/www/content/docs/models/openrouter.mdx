title: OpenRouter
description: 500+ active models on 80+ providers with a single API key.
---

## Set your key

```bash
export OPENROUTER_API_KEY="..."
```

`OPENROUTER_API_KEY` is also available through **Use an API key**.

## Run

```bash
codework run \
  --provider openrouter \
  --model meta/muse-spark-1.3-contributor \
  "Plan database migration"
```
