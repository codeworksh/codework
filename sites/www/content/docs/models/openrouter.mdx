title: OpenRouter
description: Reach hundreds of models from many providers with a single API key.
---

[OpenRouter](https://openrouter.ai) routes one API key to models from Anthropic, OpenAI, Google, DeepSeek, Meta, and many more. It's the quickest way to try models side by side.

## Set Your Key

Create a key at [openrouter.ai/keys](https://openrouter.ai/keys), then:

```bash
export OPENROUTER_API_KEY="..."
```

Add it to your shell profile so it's set in every terminal. For an editor, also add it to the agent's `env` (see [Zed](/docs/cli/acp#zed)).

## Run

Model IDs are OpenRouter's own, in `vendor/model` form:

```bash
codework run \
  --provider openrouter \
  --model deepseek/deepseek-v4.1-flash \
  "Plan the database migration"
```

List every OpenRouter model CodeWork can use:

```bash
codework models --provider openrouter
```

## Pricing

You pay OpenRouter at its listed rates. The usage summary at the end of each run estimates the cost from the [catalog](/docs/models/catalog), whose prices come from models.dev and track OpenRouter's.
