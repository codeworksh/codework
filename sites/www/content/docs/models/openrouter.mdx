---
title: OpenRouter
description: Reach hundreds of models from many providers with a single API key.
---

[OpenRouter](https://openrouter.ai) gives you one API key for models from Anthropic, OpenAI, Google, DeepSeek, Meta, and many more. It's the quickest way to try models side by side.

## Set your key

Create a key at [openrouter.ai/keys](https://openrouter.ai/keys), then:

```bash
export OPENROUTER_API_KEY="..."
```

Add it to your shell profile so it's set in every terminal. If you use CodeWork from an editor, also add it to the agent's `env` (see [Zed](/docs/integrations/acp#zed)).

## Run

Model IDs are OpenRouter's own, in `vendor/model` form:

```bash
codework run \
  --provider openrouter \
  --model deepseek/deepseek-v4.1-flash \
  "Plan the database migration"
```

List every OpenRouter model CodeWork can use:

```bash
codework models --provider openrouter
```

The list shows only models that support tool calling. If your key is set when the catalog downloads, the list narrows to the models your key can use. After you first set the key, run `codework models refresh --force` to narrow the list right away.

## Pricing

You pay OpenRouter at its listed rates. The usage summary at the end of each run estimates the cost from the [catalog](/docs/models/catalog). The catalog takes OpenRouter's prices from OpenRouter, for your key, each time it downloads.
