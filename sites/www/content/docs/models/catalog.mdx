CodeWork reads models from a catalog in your CodeWork home. The catalog lists each model's provider, context window, input types, reasoning support, and price. `--provider`, `--model`, and your editor's model picker all choose from it.

```bash
codework models                         # every model, as provider/model
codework models --provider openai-codex # one provider
codework models providers               # provider IDs only
```

`codework models` lists the downloaded catalog. Models you add in [settings](/docs/models/custom) aren't in this list. You can still run them, and they appear in editor model pickers.

## Where the catalog comes from

| Provider                                      | Source                                                                                  |
| --------------------------------------------- | --------------------------------------------------------------------------------------- |
| [OpenAI Codex](/docs/models/openai-codex)     | A fixed list maintained in CodeWork, priced at OpenAI's API rates (below).              |
| [GitHub Copilot](/docs/models/github-copilot) | [models.dev](https://models.dev), adjusted for Copilot's endpoints and thinking levels. |
| [OpenRouter](/docs/models/openrouter)         | OpenRouter's own model list, narrowed to what your `OPENROUTER_API_KEY` can use.        |
| Every other provider                          | [models.dev](https://models.dev): any provider whose models support tool calling.       |
| [Your own models](/docs/models/custom)        | The `models` array in your settings, added to the catalog.                              |

CodeWork downloads the catalog to `~/.codework/models.gen.json` and downloads a fresh copy once it's older than 15 minutes. Change that window with `CODEWORK_MODELS_TTL`, or refresh it now:

```bash
codework models refresh --force
```

If a download fails, the last catalog stays in use. With no catalog at all, CodeWork falls back to a built-in one that covers only Anthropic, OpenAI, and OpenRouter.

To use your own catalog file, point `CODEWORK_MODELS_FILE` at it. CodeWork reads the file and reloads it whenever it changes. Only `codework models refresh` writes to it.

## How pricing works

Prices are in US dollars **per million tokens**, with four rates per model:

| Rate        | Charged for                                                       |
| ----------- | ----------------------------------------------------------------- |
| Input       | Prompt tokens the provider hasn't cached                          |
| Output      | Tokens the model generates, including reasoning tokens            |
| Cache read  | Prompt tokens served from the provider's cache                    |
| Cache write | Prompt tokens written to the cache, on providers that bill for it |

Some models also have long-context tiers. Once a request's prompt passes a threshold, with cached tokens counted, higher rates apply to the whole request. The tiers are listed under `cost.tiers` in `~/.codework/models.gen.json`.

Every `codework run` ends with a usage summary that totals these costs for the run:

```text
── usage ───────────────────────────────────────────────────────────────
model    openai-codex/gpt-5.6-luna
tokens   6,172 input · 1,377 output · 412 reasoning · 19,581 total
cache    12,032 read · 0 write
cost     $0.003127 · 3 turns
```

<Callout title="Subscriptions are billed by your plan">
	With [OpenAI Codex](/docs/models/openai-codex) or [GitHub Copilot](/docs/models/github-copilot), the cost line is
	what the same tokens would cost at API rates. What you actually pay is set by your ChatGPT or Copilot plan. Use the
	cost line to compare models, not as a bill.
</Callout>

## OpenAI Codex models

Available with `codework auth login --openai-codex`. Prices are the API-equivalent rates CodeWork uses for the usage summary, listed as input / cache read / output.

| ID                    | Price                   | Context |
| --------------------- | ----------------------- | ------- |
| `gpt-6.1-sol`         | $2.00 / $0.10 / $10.00  | 500K    |
| `gpt-6-astra`         | $10.00 / $1.00 / $50.00 | 272K    |
| `gpt-6-sol`           | $2.00 / $0.20 / $10.00  | 272K    |
| `gpt-6-luna`          | $0.10 / $0.01 / $0.50   | 272K    |
| `gpt-5.6-sol`         | $4.00 / $0.40 / $20.00  | 272K    |
| `gpt-5.6-terra`       | $2.00 / $0.20 / $12.00  | 272K    |
| `gpt-5.6-luna`        | $0.20 / $0.02 / $1.20   | 272K    |
| `gpt-5.3-codex-spark` | $1.75 / $0.175 / $14.00 | 128K    |

Every Codex model reasons, accepts images, and can write up to 128K output tokens. Above 272K prompt tokens, `gpt-6.1-sol` is priced at its long-context rates. A request served at the `flex` tier costs half; one served at `priority` costs double.

### Thinking levels

Set the level with `--thinking`, `thinkingLevel` in [settings](/docs/customize/settings#model), or the Thinking Effort picker in your editor. If you ask for a level a model doesn't support, CodeWork uses the next level up, or the model's highest level.

| Model                                                        | Levels                    |
| ------------------------------------------------------------ | ------------------------- |
| `gpt-6-sol`, `gpt-6-luna`, `gpt-5.6-luna`                    | `off` through `max`       |
| `gpt-6.1-sol`, `gpt-6-astra`, `gpt-5.6-sol`, `gpt-5.6-terra` | `minimal` through `max`   |
| `gpt-5.3-codex-spark`                                        | `minimal` through `xhigh` |

On every Codex model, `minimal` is sent as `low`.

## Top OpenRouter models

Available when `OPENROUTER_API_KEY` is set. See [OpenRouter](/docs/models/openrouter). Use the ID with the `openrouter` provider, for example `--provider openrouter --model deepseek/deepseek-v4.1-flash`.

| Model               | ID                             |

| Claude Sonnet 5.5   | `anthropic/claude-sonnet-5.5`  |
| GPT-6.1 Sol         | `openai/gpt-6.1-sol`           |
| Gemini 3.8 Flash    | `google/gemini-3.8-flash`      |
| Kimi K3             | `moonshotai/kimi-k3`           |
| DeepSeek V4.1 Flash | `deepseek/deepseek-v4.1-flash` |
| MiniMax M3          | `minimax/minimax-m3`           |

CodeWork fetches OpenRouter's prices and context windows from OpenRouter each time the catalog downloads, for your key if it's set. They can change between refreshes. The current ones are under each model's `cost` and `contextWindow` in `~/.codework/models.gen.json`.
