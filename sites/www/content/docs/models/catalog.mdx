CodeWork reads models from a catalog in your CodeWork home. The catalog lists each model's provider, context window, input types, reasoning support, and price, and it's what `--provider`, `--model`, and the model picker in your editor choose from.

```bash
codework models                         # every model, as provider/model
codework models --provider openai-codex # one provider
codework models providers               # provider IDs only
```

`codework models` lists the downloaded catalog. Models you add in [settings](/docs/models/custom) aren't in it, but you can still run them and they show in editor model pickers.

## Where the Catalog Comes From

| Provider                                      | Source                                                                                  |
| --------------------------------------------- | --------------------------------------------------------------------------------------- |
| [OpenAI Codex](/docs/models/openai-codex)     | A fixed list maintained in CodeWork, priced at OpenAI's API rates (below).              |
| [GitHub Copilot](/docs/models/github-copilot) | [models.dev](https://models.dev), adjusted for Copilot's endpoints and thinking levels. |
| [OpenRouter](/docs/models/openrouter)         | OpenRouter's own model list, narrowed to what your `OPENROUTER_API_KEY` can use.        |
| Every other provider                          | [models.dev](https://models.dev): any provider whose models support tool calling.       |
| [Your own models](/docs/models/custom)        | The `models` array in your settings, added to the catalog.                              |

CodeWork downloads the catalog to `~/.codework/models.gen.json` and downloads it again when it's older than 15 minutes. Change that window with `CODEWORK_MODELS_TTL`, or refresh it now:

```bash
codework models refresh --force
```

If a download fails, the last catalog stays in use. With no catalog at all, CodeWork falls back to a built-in one that covers only Anthropic, OpenAI, and OpenRouter.

To use a catalog file you manage, point `CODEWORK_MODELS_FILE` at it. CodeWork reads it and reloads it when it changes, but only `codework models refresh` writes to it.

## How Pricing Works

Prices are in US dollars **per million tokens**, with four rates per model:

| Rate        | Charged for                                                       |
| ----------- | ----------------------------------------------------------------- |
| Input       | Prompt tokens the provider hasn't cached                          |
| Output      | Tokens the model generates, including reasoning tokens            |
| Cache read  | Prompt tokens served from the provider's cache                    |
| Cache write | Prompt tokens written to the cache, on providers that bill for it |

Some models also have long-context tiers: once a request's prompt, cached tokens included, passes a threshold, a higher set of rates applies to the whole request. They're listed under `cost.tiers` in `~/.codework/models.gen.json`.

Every `codework run` ends with a usage summary that adds these up for that run:

```text
── usage ───────────────────────────────────────────────────────────────
model    openai-codex/gpt-5.6-luna
tokens   6,172 input · 1,377 output · 412 reasoning · 19,581 total
cache    12,032 read · 0 write
cost     $0.003127 · 3 turns
```

<Callout title="Subscriptions are billed by your plan">
	With [OpenAI Codex](/docs/models/openai-codex) or [GitHub Copilot](/docs/models/github-copilot), the cost line is
	what the same tokens would cost at API rates. What you actually pay is set by your ChatGPT or Copilot plan. Use it to
	compare models, not as a bill.
</Callout>

## OpenAI Codex Models

Available with `codework auth login --openai-codex`. Prices are the API-equivalent rates CodeWork uses for the usage summary, as input / cache read / output.

| ID                    | Price                   | Context |
| --------------------- | ----------------------- | ------- |
| `gpt-6.1-sol`         | $2.00 / $0.10 / $10.00  | 500K    |
| `gpt-6-astra`         | $10.00 / $1.00 / $50.00 | 272K    |
| `gpt-6-sol`           | $2.00 / $0.20 / $10.00  | 272K    |
| `gpt-6-luna`          | $0.10 / $0.01 / $0.50   | 272K    |
| `gpt-5.6-sol`         | $4.00 / $0.40 / $20.00  | 272K    |
| `gpt-5.6-terra`       | $2.00 / $0.20 / $12.00  | 272K    |
| `gpt-5.6-luna`        | $0.20 / $0.02 / $1.20   | 272K    |
| `gpt-5.3-codex-spark` | $1.75 / $0.175 / $14.00 | 128K    |

Every Codex model reasons, accepts images, and can write up to 128K output tokens. Above 272K prompt tokens, `gpt-6.1-sol` is priced at its long-context rates. A request served at the `flex` tier is priced at half; `priority` at double.

### Thinking Levels

Set the level with `--thinking`, `thinkingLevel` in [settings](/docs/customize/settings#model), or the Thinking Effort picker in your editor. Ask for a level a model doesn't support and CodeWork uses the next one up, or the highest it has.

| Model                                                        | Levels                    |
| ------------------------------------------------------------ | ------------------------- |
| `gpt-6-sol`, `gpt-6-luna`, `gpt-5.6-luna`                    | `off` through `max`       |
| `gpt-6.1-sol`, `gpt-6-astra`, `gpt-5.6-sol`, `gpt-5.6-terra` | `minimal` through `max`   |
| `gpt-5.3-codex-spark`                                        | `minimal` through `xhigh` |

On every Codex model, `minimal` is sent as `low`.

| DeepSeek V4.1 Flash | `deepseek/deepseek-v4.1-flash` |

OpenRouter's prices and context windows come from OpenRouter when the catalog downloads, for your key when it's set, so they can change between refreshes. The current ones are under each model's `cost` and `contextWindow` in `~/.codework/models.gen.json`.
