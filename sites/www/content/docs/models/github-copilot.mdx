Requires a GitHub Copilot subscription. Free plans get a limited model set.

## Sign in

Sign in with the device flow:

```bash
codework auth login --github-copilot
```

Models are served through `api.githubcopilot.com`. Run `codework models` to see which ones your plan includes.
