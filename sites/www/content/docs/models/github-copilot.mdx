Requires GitHub Copilot on your GitHub account: a subscription, a seat from your organization, or Copilot Free.

## Sign In

CodeWork uses GitHub's device flow. It shows a code, opens GitHub in your browser, and finishes once you enter it:

```bash
codework auth login --github-copilot
```

On GitHub Enterprise, pass your domain:

```bash
codework auth login --github-copilot --enterprise github.example.com
```

When you sign in, CodeWork records which models your account can use, and editor model pickers list only those. Add `--enable-models` to also turn on the models your Copilot settings haven't enabled or disabled yet. Sign in again after your plan or your organization's Copilot policies change.

To sign in a running `codework serve` instead of this machine, add `--server ws://127.0.0.1:7433/rpc/v1`.

## Run

```bash
codework models --provider github-copilot
codework run --provider github-copilot --model claude-sonnet-5.5 "Explain this repository"
```

`codework models` lists every Copilot model in the catalog, including ones your account can't use.

Requests go to the Copilot API host GitHub gives your account at sign-in, or your Enterprise's Copilot endpoint.

## Thinking

Claude Opus 5.5, Claude Sonnet 5.5, and the Claude Fable models on Copilot can't turn thinking off. GPT models that OpenAI lets turn reasoning off, such as `gpt-6-luna` and `gpt-5.6-luna`, accept `off` here too.

## Use a Token Instead

Set `COPILOT_GITHUB_TOKEN` and CodeWork uses it instead of the stored login. `GITHUB_TOKEN` and `GH_TOKEN` are never read.

## Check or Remove the Login

```bash
codework auth status --github-copilot
codework auth logout --github-copilot
```

Copilot logins don't expire. If requests keep failing with 401, sign in again.

## Pricing

Usage counts against your Copilot plan. The cost in CodeWork's usage summary is the API-rate equivalent, useful for comparing models but not what you're billed.
