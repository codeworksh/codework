You need GitHub Copilot on your GitHub account: a subscription, a seat from your organization, or Copilot Free.

## Sign in

CodeWork signs in with GitHub's device flow. It shows a code and opens GitHub in your browser. Sign-in finishes once you enter the code there.

```bash
codework auth login --github-copilot
```

On GitHub Enterprise, pass your domain:

```bash
codework auth login --github-copilot --enterprise github.example.com
```

When you sign in, CodeWork records which models your account can use, and editor model pickers list only those. Add `--enable-models` to also turn on models you haven't yet enabled or disabled in your Copilot settings. Sign in again after your plan or your organization's Copilot policies change.

To store the login on a running `codework serve` instead of this machine, add `--server ws://127.0.0.1:7433/rpc/v1`.

## Run

```bash
codework models --provider github-copilot
codework run --provider github-copilot --model claude-sonnet-5.5 "Explain this repository"
```

`codework models` lists every Copilot model in the catalog, including ones your account can't use.

Requests go to the Copilot API host that GitHub assigns your account at sign-in, or to your Enterprise's Copilot endpoint.

## Thinking

On Copilot, you can't turn thinking off for Claude Opus 5.5, Claude Sonnet 5.5, or the Claude Fable models. GPT models that OpenAI lets you run with reasoning off, such as `gpt-6-luna` and `gpt-5.6-luna`, accept `off` on Copilot too.

## Use a token instead

Set `COPILOT_GITHUB_TOKEN` and CodeWork uses it instead of the stored login. `GITHUB_TOKEN` and `GH_TOKEN` are never read.

## Check or remove the login

```bash
codework auth status --github-copilot
codework auth logout --github-copilot
```

Copilot logins don't expire. If requests keep failing with 401, sign in again.

## Pricing

Usage counts against your Copilot plan. The cost in CodeWork's usage summary is what the same tokens would cost at API rates. Use it to compare models. It isn't what you're billed.
