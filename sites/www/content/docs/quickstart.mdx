title: Quickstart
description: Install CodeWork, connect a model, and make your first change in a few minutes.
---

You'll install CodeWork, connect a model, ask about your codebase, have it make a small change, and review what it did. Use the [desktop app](/docs/desktop) or your terminal. Both need the CLI, so you install it first.

## 1. Install CodeWork

```bash title="curl"
curl -fsSL https://codework.sh/install | sh
```

```bash title="pnpm"
pnpm add -g @codeworksh/cli
```

The curl script installs a standalone binary that needs no Node.js, on macOS (Apple silicon) and Linux (arm64, x64, glibc). The pnpm package needs Node.js 24.14.1 or later and works on other platforms too.

Check that it's on your `PATH`:

```bash
codework --help
```

See [Installation](/docs/cli/installation) for updating and uninstalling.

## 2. Connect a model

Sign in with a ChatGPT Plus or Pro plan:

```bash
codework auth login --openai-codex
```

Or set an API key. OpenRouter gives you hundreds of models with one key:

```bash
export OPENROUTER_API_KEY="..."
```

[Models & pricing](/docs/models) covers every provider, including Copilot, Anthropic, Gemini, and local models.

## 3. Ask about your codebase

### Desktop app

[Download the app](/docs/desktop#download), open **Settings → Providers**, and press **Start**. Then press **New session**, pick your project with **Select project → New…**, and ask:

```text
Explain how this repository is structured and how to run its checks.
```

![The start page, with a project picked and the prompt box ready](/images/docs/desktop/start.webp)

### Terminal

From your project folder, pick the provider you connected:

```bash title="ChatGPT plan"
codework run \
  --provider openai-codex \
  --model gpt-5.6-luna \
  "Explain how this repository is structured and how to run its checks."
```

```bash title="OpenRouter key"
codework run \
  --provider openrouter \
  --model deepseek/deepseek-v4.1-flash \
  "Explain how this repository is structured and how to run its checks."
```

It prints the session ID first, streams the answer as it arrives, and ends with the tokens and cost of the run.

CodeWork searches the repo, reads the files that matter, and summarizes how the project fits together.

## 4. Make a change

Ask in the same session, so CodeWork remembers what it already learned.

### Desktop app

Type in the session's prompt box and press Enter. If the agent is still working, Enter [steers](/docs/desktop/steer) it: the agent reads your message during its current turn.

### Terminal

```bash
codework run \
  --session <session-id> \
  "Add a short 'Development' section to the README with the commands you found. Then run the checks."
```

Good first tasks are small and easy to review: docs, a copy fix, a failing test, one function.

<Callout type="warn">
	CodeWork doesn't ask before it edits files or runs commands. Start in a git repository with a clean working tree so
	every change is easy to see and undo.
</Callout>

## 5. Review the result

```bash
git diff
```

Keep what you like, or ask for changes in the same session. Throw everything away with `git restore .`.

## 6. Set a default model

Save the model in your settings so you can drop the flags:

```jsonc title="~/.codework/settings.jsonc"
{
	// With a ChatGPT plan: { "provider": "openai-codex", "id": "gpt-5.6-luna" }
	"model": { "provider": "openrouter", "id": "deepseek/deepseek-v4.1-flash" },
}
```

```bash
codework run "Find and fix one flaky test"
```
