## Install

```bash title="curl"
curl -fsSL https://codework.sh/install | sh
```

```bash title="pnpm"
pnpm add -g @codeworksh/cli
```

The curl script installs a standalone binary that doesn't need Node.js. It supports macOS (Apple silicon) and Linux (arm64, x64, glibc). On other systems, such as Intel Macs or Linux with musl, the script stops and points you to pnpm. The pnpm package needs Node.js 24.14.1 or later.

The curl script installs one `codework` binary to `~/.codework/bin`, or to `CODEWORK_INSTALL_DIR` if you set it. If that folder isn't on your `PATH`, the script adds it to your shell's startup file (zsh, bash, or fish) and tells you to open a new shell. For other shells, it prints the line for you to add.

| Flag                  | What it does                                |
| --------------------- | ------------------------------------------- |
| `--dev`               | Install the newest development build        |
| `--version <version>` | Install a specific release, such as `0.6.0` |
| `--no-modify-path`    | Leave your shell's startup file alone       |

Pass flags after `sh -s --`, as in `curl -fsSL https://codework.sh/install | sh -s -- --dev`.

Check that `codework` is on your `PATH`:

```bash
codework --help
```

Every command is `codework <command>`. Add `--help` to any command to see its flags.

## Connect a model

CodeWork needs access to at least one model provider. You can sign in with a subscription:

```bash
codework auth login --openai-codex
codework auth login --github-copilot
```

Or set an API key:

```bash
export OPENROUTER_API_KEY="..."
export GEMINI_API_KEY="..."
```

Credentials from `codework auth login` are stored in your CodeWork home (`~/.codework` by default) and refreshed automatically. See [Models & Pricing](/docs/models) for every provider.

Check what CodeWork can see:

```bash
codework auth status --openai-codex
codework models
```

## Where CodeWork keeps its files

| Path                                 | What's in it                                                   |
| ------------------------------------ | -------------------------------------------------------------- |
| `~/.codework/settings.jsonc`         | User settings: default model, plugins                          |
| `~/.codework/aikit/auth.json`        | Subscription credentials                                       |
| `~/.codework/mcp.json`               | Your MCP servers                                               |
| `~/.codework/mcpauth.json`           | MCP server sign-ins                                            |
| `~/.codework/models.gen.json`        | The model catalog, downloaded again when older than 15 minutes |
| `<project>/.codework/settings.jsonc` | Project settings, layered over your user settings              |
| `<project>/.codework/mcp.json`       | Project MCP servers                                            |

Use `--home` on any command, or set `CODEWORK_HOME_DIR`, to point CodeWork at a different home.

## Update

```bash title="curl"
curl -fsSL https://codework.sh/install | sh
```

```bash title="pnpm"
pnpm add -g @codeworksh/cli@latest
```

## Uninstall

If you installed with curl, delete `~/.codework/bin/codework` and the `PATH` line the script added to your shell's startup file.

```bash title="pnpm"
pnpm remove -g @codeworksh/cli
```

Either way, `~/.codework` stays in place. Delete it too if you want to remove your sessions, settings, and credentials.
