The `codework` CLI is the main way to use CodeWork. It runs agent sessions in your repository or in a sandbox, manages models and plugins, and powers every other interface: `codework acp` serves editors and `codework serve` starts the RPC server.

## Getting Started

```bash
pnpm add -g @codeworksh/cli
```

Then, from your project folder:

```bash
codework run "Explain how this repository is structured"
```

## Running a Prompt

`codework run` sends one prompt, streams CodeWork's answer to your terminal, and exits when the turn is done. It prints the session ID so you can continue later.

```bash
codework run "Inspect the failing tests"
```

Start the session somewhere other than the current directory with `--cwd`:

```bash
codework run --cwd ~/work/api "Add a health check endpoint"
```

Pick a model per run with `--provider` and `--model`. Add `--thinking` to set reasoning effort on models that support it.

```bash
codework run --provider openrouter --model deepseek/deepseek-v4.1-flash --thinking medium "Plan the database migration"
```

Browse what's available with `codework models`. See [Models](/docs/models) to connect a provider.
