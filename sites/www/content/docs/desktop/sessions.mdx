## Start a Session

1. Press **New session** in the sidebar.
2. Under the prompt box, pick **Select project → New…** and choose a folder.
3. Describe the task and press Enter.

Shift+Enter adds a new line. The session opens as soon as it starts.

### Model and Reasoning

Pick a model and a reasoning level under the prompt box, or leave them for your [settings](/docs/customize/settings) to decide. The app remembers your picks; the project folder resets when the app restarts.

**Reasoning** lists only the levels the model supports. A model whose provider has no credentials shows muted and can't be picked.

## Find a Session

The sidebar lists every session, newest first, with its project and age. **Search** matches session titles and project names.

To see sessions grouped by project, press ⌘K and pick **Open Projects**.

## Open a Session

| Click                    | Opens the session                      |
| ------------------------ | -------------------------------------- |
| Click                    | In place, or where it's already open   |
| ⌘-click, or middle-click | In a new pane, beside what's on screen |
| ⇧-click                  | In a new workspace of its own          |

On Linux, use Ctrl in place of ⌘. [Workspaces and panes](/docs/desktop/workspaces) explains the layout.
