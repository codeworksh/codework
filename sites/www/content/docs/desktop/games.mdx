title: Games
description: Dino and invaders, for when the agent is busy and you aren't.
---

![The dino game running full screen in the desktop app](/images/landing/app/game.webp)

The start page plays dino and invaders on autopilot. Hover the band and press **take control** to play; Esc or **release** hands it back.

| Game     | Controls                                      |
| -------- | --------------------------------------------- |
| Dino     | Space or ↑ to jump, ↓ to duck                 |
| Invaders | ← → to move, Space or ↑ to fire. Three lives. |

Pick **low**, **mid**, or **hard** while you play. Your high score lasts until you leave the start page, so make it count. The games cost zero tokens.
