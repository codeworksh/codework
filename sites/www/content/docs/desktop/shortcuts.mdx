---
title: Keyboard Shortcuts
description: Every shortcut in the desktop app.
---

On Linux, use Ctrl in place of ⌘.

| Shortcut    | Action                                   |
| ----------- | ---------------------------------------- |
| ⌘K          | Open the command palette                 |
| ⌘B          | Show or hide the sidebar                 |
| ⌘1 to ⌘9    | Switch to a workspace                    |
| ⌘,          | Open Settings                            |
| Esc         | Close Settings                           |
| Enter       | Send, or steer while the agent works     |
| ⌘Enter      | Queue a follow-up while the agent works  |
| Shift+Enter | New line                                 |
| ← / →       | Resize columns, with the divider focused |

The command palette opens **Projects** and switches themes. Arrow through the themes to preview each one; close the palette to keep the one you had.
